# Troubleshooting

| Symptom                                                | Check or action                                                                                                                                                                                     |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CLI file missing                                       | Use Node.js 20+ and run `npm ci` followed by `npm run build` from the checkout. The package is not yet published to npm by this repository.                                                         |
| OpenAI key required / authentication failed            | Set `OPENAI_API_KEY` in the environment or local `.env`; check the key's validity and access without printing it.                                                                                   |
| GitHub authentication, repository, or rate-limit error | Verify `--repo owner/repository`, PR number, token permissions, and repository visibility. Retry transient failures later.                                                                          |
| Unexpected configuration                               | Configuration comes from the PR base SHA, not your local checkout or PR head. Check CLI overrides and spelling against [configuration](configuration.md).                                           |
| Budget failure or skipped patches                      | Compare reserves against the usable diff formula. Default usable diff is 40,000 characters; per-patch maximum is 30,000. Increasing character limits is not proof the selected model supports them. |
| Empty findings / unknown risk                          | Check `batchCount`, reviewed count, skipped reasons, and incomplete coverage. Unknown risk does not imply no review ran; see [report interpretation](review-format.md).                             |
| Output file write failure                              | Ensure the parent directory exists and is writable; the CLI does not create missing parent directories.                                                                                             |
| Action key unavailable on a fork                       | Repository secrets are normally withheld. Do not expose them by casually changing to `pull_request_target`.                                                                                         |
| Comment missing or stale publication skipped           | Check `post-comment`, `pull-requests: write`, token access, and the reviewed/current head. See [Action troubleshooting](github-actions.md#troubleshooting).                                         |
| Summary or comment shortened                           | Both outputs have independent limits. The Action does not upload the complete runner-temp report as an artifact.                                                                                    |
| Offline scorer rejects input                           | Build first, use manifest version 1, check unique case/label IDs, exact head, category, and valid anchors. Paths are relative to the manifest.                                                      |

When reporting a bug, include the tool version or commit, Node version, command/options with credentials removed, expected behavior, and a minimal redacted reproduction. JSON reports contain raw body and patches: do not attach private code or secrets. See [security reporting](../SECURITY.md) for sensitive issues.
